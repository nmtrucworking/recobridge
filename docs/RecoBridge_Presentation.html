06
Quyết định tích hợp

REST thắng trong MVP vì phù hợp consumer, không phải vì luôn nhanh nhất

REST / JSON

Chọn cho MVP
  • Tích hợp trực tiếp với Website/BFF
  • OpenAPI, debug và demo đơn giản
  • Latency đủ xa dưới budget 200 ms
  • Đổi lại: synchronous coupling

gRPC

Không cần lúc này
  • Tốt cho internal service throughput cao
  • Protobuf contract mạnh
  • Web cần adapter hoặc gRPC-web
  • Chưa đủ lợi ích để bù tooling

Message Broker

Target khi scale
  • Tốt cho feedback bất đồng bộ
  • Giảm coupling theo thời gian
  • Không thay request top-N đồng bộ
  • Chưa có downstream consumer thật trong MVP

03 · RETRY SAFE

Nếu PostgreSQL down: recommendation vẫn phục vụ bằng artifact local; riêng event endpoint trả 503 rõ ràng. Circuit breaker là target khi có dependency remote, không được trình bày như tính năng MVP đã chạy.

Kết luận bảo vệ

RecoBridge chứng minh một giải pháp tích hợp trung thực, có failure handling và có đường nâng cấp rõ.

Giá trị không nằm ở việc gắn nhãn “AI”, mà ở khả năng truy vết từ dữ liệu → quyết định → API → trải nghiệm → feedback.
